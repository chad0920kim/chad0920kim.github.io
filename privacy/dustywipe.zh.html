隐私政策

细尘一览 (com.anonymous.dustywipe) · 最后更新：2026年11月8日

1. 我们收集和使用的信息

  • 无需注册或登录即可使用，开发者不运营任何服务器。
  • 位置信息（精确位置和大致位置）：仅在您授予位置权限时使用，用于显示您所在地的空气质量（微尘）和天气。仅在您使用应用时，或锁屏空气质量显示功能开启且其服务正在运行时（此期间状态栏会显示通知）获取位置。应用和该服务均关闭时，不会获取位置。
  • 不会保存位置坐标和移动记录。为便于显示，最近查询的地区名称、空气质量与天气结果以及应用设置可能会保存在设备上。

2. 发送到设备之外的信息

  • 韩国气象厅短期预报 API（公共数据门户 data.go.kr）：发送由您的位置换算出的预报网格坐标（nx、ny，约 5 公里网格）、预报基准时间和应用的 API 密钥。不会发送精确的经纬度。
  • 韩国环境公团 AirKorea 大气污染信息 API（公共数据门户 data.go.kr）：发送最近的监测站名称（例如"钟路区"）和应用的 API 密钥。
  • 地址转换（Geocoder）：为将位置坐标转换为市/区名称，应用使用 Android 设备内置的地址转换功能。该功能由设备制造商或 Google 的位置服务处理，此时您的坐标可能会传递给该服务。
  • 新闻标题：锁屏上显示的韩国主要新闻标题来自 Google 新闻 RSS。该请求不包含位置或个人信息。
  • 与所有网络请求一样，接收请求的服务器可以看到您的 IP 地址。本应用与上述机构和服务无合作关系，仅使用公开的公共数据和新闻源。

3. 权限及其用途

  • 位置：仅用于上文"我们收集和使用的信息"中所述的目的。
  • 显示在其他应用上层：用于在锁屏上方显示空气质量雾化效果和信息。
  • 通知、前台服务、开机启动：用于提示锁屏空气质量显示功能正在运行，并在设备重启后重新启动您已开启的功能。

4. 广告（Google AdMob）

本应用通过 Google AdMob 在屏幕底部显示横幅广告。为投放广告、衡量效果及防止欺诈，Google 可能会收集设备的广告 ID、根据 IP 地址推断的大致位置、设备信息（型号、系统版本等）以及广告展示和点击信息。这些信息依照 Google 的政策处理，开发者不会获得可识别个人身份的信息。您可以在设备设置的 Google > 广告 中重置或删除广告 ID。详情请参阅 Google 的广告政策。应用使用的 GPS 位置不会用于广告，锁屏显示中也不会出现广告。

5. 儿童隐私

细尘一览 并非专门面向儿童的应用，我们不会故意收集 13 岁以下儿童的个人信息。

6. 数据的保存与删除

本应用没有应用内购买。保存在设备上的地区名称、查询结果和设置会在清除应用数据或卸载应用时一并删除。您可以随时在设备设置中关闭位置权限。
