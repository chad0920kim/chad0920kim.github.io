プライバシーポリシー

ダスティワイプ (com.anonymous.dustywipe) ・最終更新日 2026年11月8日

1. 収集・利用する情報

  • 会員登録やログインなしで利用でき、開発者が運営するサーバーはありません。
  • 位置情報（正確な位置・おおよその位置）：現在地の微細粉塵（PM）と天気を表示するため、ユーザーが位置情報の権限を許可した場合にのみ使用します。位置はアプリの使用中、またはロック画面の大気質表示機能がオンでそのサービスが実行中の時（この間はステータスバーに通知が表示されます）に確認します。アプリとこのサービスがどちらもオフの時は位置を確認しません。
  • 位置座標や移動履歴は保存しません。表示のため、最近確認した地域名、大気質・天気の結果、アプリ設定が端末内に保存される場合があります。

2. 端末の外へ送信される情報

  • 韓国気象庁 短期予報 API（公共データポータル data.go.kr）：位置を約 5km 単位の予報格子座標（nx, ny）に変換した値、予報基準時刻、アプリの API キーを送信します。正確な緯度・経度は送信しません。
  • 韓国環境公団 エアコリア大気汚染情報 API（公共データポータル data.go.kr）：最寄りの測定所名（例：鍾路区）とアプリの API キーを送信します。
  • 住所変換（Geocoder）：位置座標を市・区の名前に変換するため、Android 端末の住所変換機能を使用します。この機能は端末メーカーまたは Google の位置情報サービスが処理し、その際に位置座標が当該サービスに渡される場合があります。
  • ニュース見出し：ロック画面に表示する韓国の主要ニュースの見出しを Google ニュース RSS から取得します。このリクエストに位置や個人情報は含まれません。
  • インターネット通信の性質上、リクエストを受け取るサーバーには接続元の IP アドレスが伝わります。本アプリは上記の機関・サービスと提携関係になく、公開されている公共データとニュースフィードを利用しています。

3. 権限の利用目的

  • 位置情報：上記「収集・利用する情報」に記載した目的にのみ使用します。
  • 他のアプリの上に表示：ロック画面の上に大気質の霧エフェクトと情報を表示するために使用します。
  • 通知・フォアグラウンドサービス・起動時の実行：ロック画面の大気質表示機能が実行中であることを知らせ、端末の再起動後もユーザーがオンにした機能を再開するために使用します。

4. 広告（Google AdMob）

本アプリは Google AdMob を通じて画面下部にバナー広告を表示します。広告の配信、効果測定、不正防止のため、Google は端末の広告 ID、IP アドレスから推定したおおよその位置、端末情報（機種・OS バージョンなど）、広告の表示・クリック情報を収集することがあります。これらの情報は Google のポリシーに従って処理され、開発者が個人を特定できる情報を受け取ることはありません。広告 ID は端末の設定の Google > 広告 からリセットまたは削除できます。詳しくは Google の広告に関するポリシーをご覧ください。アプリが使用する GPS 位置情報は広告には使用せず、ロック画面の表示に広告は出ません。

5. 児童のプライバシーについて

ダスティワイプは児童を対象として特別に制作されたアプリではなく、13歳未満の児童から意図的に個人情報を収集することはありません。

6. データの保存と削除

本アプリにはアプリ内購入はありません。端末に保存された地域名・結果・設定は、アプリのデータを消去するかアプリを削除すると一緒に削除されます。位置情報の権限は端末の設定でいつでもオフにできます。
