개인정보처리방침

한눈에 미세먼지 (com.anonymous.dustywipe) · 최종 수정일 2026-11-05

1. 수집·이용하는 정보

  • 회원가입이나 로그인 없이 사용할 수 있으며, 개발자가 운영하는 서버가 없습니다.
  • 위치 정보(정밀·대략 위치): 현재 있는 곳의 미세먼지·날씨를 보여 주기 위해, 사용자가 위치 권한을 허용한 경우에만 사용합니다. 위치는 앱을 사용하는 동안, 또는 잠금화면 대기질 표시 기능이 켜져 있어 그 서비스가 실행 중일 때(이때 상태 표시줄에 알림이 표시됩니다) 확인합니다. 앱과 이 서비스가 모두 꺼져 있을 때는 위치를 확인하지 않습니다.
  • 위치 좌표와 이동 기록은 저장하지 않습니다. 화면 표시를 위해 최근 조회한 지역 이름과 대기질·날씨 결과, 앱 설정은 기기 안에 저장될 수 있습니다.

2. 외부로 전송되는 정보

  • 기상청 단기예보 API(공공데이터포털 data.go.kr): 위치를 약 5km 단위의 예보 격자 좌표(nx, ny)로 바꾼 값과 예보 기준 시각, 앱의 API 키를 보냅니다. 정밀한 위도·경도는 보내지 않습니다.
  • 한국환경공단 에어코리아 대기오염정보 API(공공데이터포털 data.go.kr): 가까운 측정소 이름(예: 종로구)과 앱의 API 키를 보냅니다.
  • 주소 변환(Geocoder): 위치 좌표를 시·구 이름으로 바꾸기 위해 Android 기기의 주소 변환 기능을 사용합니다. 이 기능은 기기 제조사 또는 Google의 위치 서비스가 처리하며, 이때 위치 좌표가 해당 서비스로 전달될 수 있습니다.
  • 뉴스 헤드라인: 잠금화면에 표시할 국내 주요 뉴스 제목을 Google 뉴스 RSS에서 가져옵니다. 이 요청에는 위치나 개인정보가 포함되지 않습니다.
  • 인터넷 통신의 특성상 요청을 받는 서버에는 접속 IP 주소가 전달됩니다. 이 앱은 위 기관·서비스와 제휴 관계가 아니며, 공개된 공공데이터와 뉴스 피드를 이용합니다.

3. 권한 사용 목적

  • 위치: 위 '수집·이용하는 정보'에 적은 목적에만 사용합니다.
  • 다른 앱 위에 표시: 잠금화면 위에 대기질 안개 효과와 정보를 보여 주기 위해 사용합니다.
  • 알림·포그라운드 서비스·부팅 후 실행: 잠금화면 대기질 표시 기능이 실행 중임을 알리고, 기기를 다시 켠 뒤에도 사용자가 켜 둔 기능을 다시 시작하기 위해 사용합니다.

4. 아동 대상 서비스 여부

한눈에 미세먼지는 특정하게 아동을 대상으로 제작된 앱이 아니며, 만 13세 미만 아동으로부터 의도적으로 개인정보를 수집하지 않습니다.

5. 정보의 보관 및 삭제

이 앱에는 광고와 인앱 결제가 없습니다. 기기에 저장된 지역 이름·조회 결과·설정은 앱 데이터를 지우거나 앱을 삭제하면 함께 삭제됩니다. 위치 권한은 기기 설정에서 언제든 끌 수 있습니다.
